# ROLES Y FLUJOS — SEAZEP-WEB

## Roles
### ADM único
Control total del sistema.

Puede:
- aprobar usuarios;
- ver empresas;
- crear softwares;
- subir manuales;
- asignar manuales a usuarios/empresas;
- ver licencias;
- ver activaciones;
- revisar consultas diarias de licencia;
- bloquear o revocar licencias;
- registrar renovaciones.

### Usuario registrado
Puede:
- iniciar sesión;
- ver manuales asignados;
- descargar documentos autorizados;
- ver softwares asociados;
- solicitar soporte o información.

## Flujo de solicitud empresarial
```txt
Visitante → SmartPozo360 → Solicitar adquisición → Formulario → Admin revisa → Contacto comercial → Licencia
```

## Flujo de manuales
```txt
Usuario se registra → Admin aprueba → Admin asigna acceso → Usuario descarga manuales
```

## Flujo de licencia
```txt
Empresa compra/contrata → Admin genera licencia → Cliente activa software → App reporta activación → Admin visualiza estado
```
