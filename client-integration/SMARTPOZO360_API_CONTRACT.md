# SmartPozo360 — Contrato técnico de integración con SEAZEP-WEB

## 1. Propósito

Este documento define la forma en que el software SmartPozo360 debe comunicarse con la API de SEAZEP-WEB para validar licencias, registrar activaciones por equipo y bloquear el uso cuando la licencia, empresa o dispositivo no cumplan las reglas comerciales.
